## 2. 동작 구조

```
폰/PC 브라우저 (GitHub Pages의 앱 화면)
   ├─ 라벨 사진 → Claude API (이미지 인식 + 웹 검색) → 칸 자동 채움
   └─ 저장·목록 → 구글시트 Apps Script 웹 앱 (비밀키로 보호)
                     ├─ 시트 Bottles 탭에 한 줄씩 저장
                     └─ 사진은 드라이브 '술곳간 사진' 폴더에 저장
```

- 앱은 빌드 과정이 없는 순수 HTML·JS입니다. 파일을 고치고 GitHub에 올리면 1~2분 뒤 앱 주소에 반영됩니다.
- Claude API 키는 시트 스크립트 설정(스크립트 속성)에 보관되고, 연결된 기기들이 같이 씁니다.
- 연결하지 않은 기기는 그 기기 안(IndexedDB)에만 저장합니다.

## 3. 파일별 역할

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 (상단, 탭 4개, 목록 자리, 등록 버튼) |
| `css/app.css` | 디자인. 탭별 분위기는 `body[data-theme="…"]` 블록으로 나뉨 |
| `js/app.js` | 화면 동작 전부 (목록·상세·등록·설정·테마 전환). 맨 위 `VERSION` |
| `js/ai.js` | Claude에 보내는 지시문(프롬프트)과 응답 형식. AI가 채우는 칸을 바꾸려면 여기 |
| `js/i18n.js` | 화면 문구 (한국어·영어), 종류 목록(레드·화이트…, 싱글몰트…, 사케…) |
| `js/store.js` | 저장소 연결 (구글시트 / 이 기기), 사진 주소 |
| `sw.js` | 오프라인·업데이트 처리. 맨 위 `VERSION`을 올려야 폰이 새 파일을 받음 |
| `apps-script/Code.gs` | 시트에 붙는 저장 스크립트 원본. 열 순서(FIELDS)가 여기 정의됨 |
| `fonts/` | 한글 도트 글꼴 갈무리 (SIL OFL, 라이선스 파일 포함) |
| `icons/px/` | 도트 술병·아이콘 그림 (a=위스키 셀러, c=와인/공용, e1=주막, e2=네온) |

## 4. 탭별 분위기

| 탭 | 테마 이름 (`data-theme`) | 모양 |
|---|---|---|
| 전체 | `all` · E1 주막 쪽빛 | 쪽빛 바탕, '술곳간' 세로 깃발, 한지 카드 + 붉은 낙관, 제목 '주막 선반' |
| 와인 | `wine` · W3 포도밭 노을 | 노을 층 바탕, RPG 대화창 목록, ▶ 커서, 레드·화이트 병 수 막대 |
| 위스키 | `whisky` · A 지하 셀러 | 어두운 나무색 + 호박색, 인벤토리 카드 격자 |
| 기타 | `other` · E2 이자카야 네온 | 밤 벽돌 바탕, 빨간 등롱, 술마다 다른 네온 색 카드 |

상세·등록·설정 화면은 지금 보고 있는 탭의 분위기를 따라갑니다. 목록 사진은 기본적으로 선명하게 나오고, 설정 → 화면에서 도트 사진으로 바꿀 수 있습니다.

| E | type | 세부 종류 | X | opened | 개봉 |
| F | vintage | 빈티지 | Y | remaining | 남은 양 % |
| G | age | 숙성 연수 | Z | price | 구매가 |
| H | country | 국가 | AA | qty | 수량 |
| I | region | 지역 | AB | purchased | 구매일 |
| J | producer | 생산자·증류소 | AC | shop | 구매처 |
| K | grapes | 품종 | AD | location | 보관 위치 |
| L | cask | 캐스크 | AE | desc | 술 소개 |

## 6. 고칠 때 순서

### 앱 화면·기능만 고칠 때
1. NAS 폴더의 파일 수정
2. `js/app.js`의 `VERSION`과 `sw.js`의 `VERSION`을 함께 올리기 (예: 0.3.4 → 0.3.5)
3. GitHub에 올리기 → 1~2분 뒤 자동 배포
4. 폰은 앱을 열면 새 버전을 받아 한 번 새로고침함. 설정 맨 아래 버전 번호로 확인

### 칸(열)을 새로 추가할 때 — 순서 중요
1. `apps-script/Code.gs`의 `FIELDS`에 새 칸을 원하는 위치에 추가 (숫자면 `NUMERIC`에도)
2. Apps Script 편집기에 같은 내용 반영 후 **저장만** (아직 배포하지 않음)
3. 시트 `Bottles`에 같은 위치로 열 삽입, 1행에 제목 입력
4. 곧바로 **배포 → 배포 관리 → 편집 → 버전: 새 버전 → 배포** (주소는 그대로 유지됨)
5. 앱 쪽(`app.js`, `ai.js`, `i18n.js`)에 새 칸 추가 후 GitHub에 올리기
6. **3~4번 사이에는 앱에서 저장하지 않기.** 예전 스크립트가 옛 순서로 써서 칸이 밀립니다. (v0.3.0 때 실제로 2병이 밀려 바로잡은 적 있음)

### AI가 채우는 내용을 바꿀 때
- `js/ai.js`의 `SCHEMA_HINT`(응답 형식)와 `prompt()`(지시문)를 수정
- 현재 규칙: 라벨이나 출처에서 확인되지 않으면 추측하지 않고 빈칸, 읽는 법은 원어 발음대로 한글 표기, 웹 검색 최대 4회
- 모델: 설정에서 Sonnet(정확) / Haiku(절약) 선택

## 7. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 고쳤는데 폰에 안 바뀜 | `VERSION` 두 곳을 올렸는지. 크롬에서 앱 주소를 열고 당겨서 새로고침 |
| 저장 실패 (unauthorized) | 연결 링크의 비밀키가 바뀌었는지. `resetSecret`을 실행했다면 새 링크로 다시 연결 |
| AI 인식 실패 | Console 잔액(월 $100 크레딧 남았는지), 키가 꺼지지 않았는지 |
| 칸이 엉뚱하게 들어감 | 시트 열 순서와 `Code.gs`의 `FIELDS` 순서가 같은지 |
